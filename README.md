# 飞机大战 · Plane War

一款纯前端实现的 Canvas 飞机大战小游戏：**无尽模式**、多机型敌机与编队、三阶段 Boss 战、Roguelite 升级系统、视差星空与全矢量美术。零依赖、零构建，`index.html` 双击即可运行。

## 快速开始

- **本地运行**：直接双击打开 `index.html`（无需服务器、无需构建）。
- **本地服务器**（可选）：`python -m http.server 8000` 后访问 `http://localhost:8000`。
- **GitHub Pages**：推送到本仓库后，在仓库 Settings → Pages 选择 `main` 分支根目录即可上线，地址为 `https://clover-four-leaf.github.io/github-pages/`。

## 操作方式

| 平台 | 移动 | 开火 |
| --- | --- | --- |
| 键盘 | WASD / 方向键 | 默认自动开火；关闭自动后按住 `Space` / `J` |
| 鼠标 | 移动鼠标追踪 | 关闭自动后按住左键 |
| 触摸 | 单指拖拽（相对锚点，不瞬移） | 自动开火 |

快捷键：`P` / `Esc` 暂停 · `Enter` / `Space` 开始或重开 · `1/2/3` 选择升级 · `F` 切换自动开火 · `M` 静音。

## 玩法规则

- **无尽模式**：无关卡设定，波次无限延续；难度随存活时间与波次递增（敌机血量、速度、射速同步提升）。
- **敌机**：三种机型（侦察机 / 战斗机 / 重型机），各有不同血量、速度、弹道（瞄准单发 / 连发点射 / 扇形散射）；波次按横排、V 字、侧翼突袭、网格四种编队进攻。
- **Boss**：每 5 波出现一只，三种 Boss 轮换（深渊毁灭者 / 苍穹蜂后 / 烈阳核舰）；独立血条 + 阶段刻度线，血量降至 66% / 33% 时进入新阶段（切换攻击模式并清屏），死亡后大额计分并掉落道具雨。
- **升级**：击杀与道具获得经验，升级时三选一强化——射速、弹道数量、伤害、护盾、生命上限、移动速度、子弹速度、僚机、拾取磁场、纳米修复、穿透弹（共 11 种）。
- **道具**：经验宝石 / 医疗包 / 护盾，带磁吸拾取。
- **计分**：击杀得分 + 波次完成奖励 + Boss 奖励；最高分存于 `localStorage`。

## 文件结构

```
index.html         入口页面（Canvas + 各界面覆盖层）
css/style.css      深空霓虹主题样式，3:5 竖屏自适应
js/utils.js        数学工具（钳制 / 插值 / 随机 / 圆角矩形）
js/config.js       全部数值配置（敌机 / Boss / 升级池）
js/input.js        键鼠触摸统一输入
js/background.js   三层视差星空 + 预渲染星云
js/sound.js        WebAudio 合成音效（无音频文件）
js/entities.js     玩家 / 敌机 / Boss / 子弹 / 道具 / 粒子实体与矢量造型
js/game.js         主控：状态机、波次导演、碰撞、HUD、界面绑定
test/harness.js    Node 无头冒烟测试（DOM/Canvas 桩，覆盖全流程）
```

## 测试

```bash
node test/harness.js
```

在 Node 中以桩模拟 DOM/Canvas 完整跑一遍：开始 → 战斗 → 升级三选一 → Boss 战与死亡演出 → 玩家死亡结算 → 重开 → 暂停/恢复，任何运行时错误都会直接抛出。

## 技术要点

- 固定 480×800 逻辑分辨率，按 `devicePixelRatio` 放大画布，窗口自适应等比缩放；
- 所有飞机、敌机、Boss、道具均为 Canvas 路径矢量绘制，无任何图片资源；
- 粒子系统（火花 / 光点 / 冲击环 / 闪光）+ 屏幕震动 + 飘字反馈；
- `requestAnimationFrame` 主循环，`dt` 钳制防止切后台跳变；标签页隐藏自动暂停。
